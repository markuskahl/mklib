🛠️ Tools & Mathematik (mklib.tools.* & mklib.math.*)

Hilfsklassen für responsive Auflösungen und mathematische Berechnungen.

1. AspectRatio (mklib.tools.AspectRatio)

Berechnet anhand der Bildschirmauflösung automatisch die optimale Spielbreite für eine feste vertikale Design-Höhe:

Eigenschaften

Eigenschaft Typ Modifizierer Beschreibung
width Int public Die berechnete Spielbreite in Pixeln.
height Int public Die berechnete Spielhöhe in Pixeln (Standard: 180).
isDefault Bool public Gibt an, ob die Fallback-Maße (400x180) verwendet wurden.
screenRatio Float private Das tatsächliche Seitenverhältnis des Displays.

Methoden

Methode Signatur Rückgabe Beschreibung
new (?screenWidth:Float = 0, ?screenHeight:Float = 0) Void Erstellt die Instanz und berechnet sofort die Maße via calc().
calc ():Void Void Führt die interne Berechnung von `width` und `height` durch.
isInRange ():Bool Bool Prüft, ob das Seitenverhältnis im Breitbildbereich (1.77 bis 2.22) liegt.

2. GamepadHelper (mklib.tools.GamepadHelper)

Hilfsklasse zum Auslösen von Gamepad-Rumble und Controller-Vibrationen über HaxeFlixel und Lime:

Methode Signatur Rückgabe Beschreibung
vibrate (gamepadID:Int = 0, lowFreq:Float = 0.5, highFreq:Float = 0.5, durationMs:Int = 200) Void Löst Controller-Vibration auf dem angegebenen Gamepad aus (Tieffrequenz- & Hochfrequenzmotor in ms).
rumble (gamepadID:Int = 0, lowFreq:Float = 0.5, highFreq:Float = 0.5, durationMs:Int = 200) Void Direkter Inline-Alias für vibrate().
stopVibration (gamepadID:Int = 0) Void Stoppt die Vibration auf dem angegebenen Gamepad sofort.
vibrateAll (lowFreq:Float = 0.5, highFreq:Float = 0.5, durationMs:Int = 200) Void Löst eine Vibration auf allen aktuell verbundenen Gamepads aus.
stopAllVibrations () Void Stoppt alle aktiven Vibrationen auf sämtlichen Gamepads.
getLimeGamepad (gamepadID:Int = 0) LimeGamepad Gibt das native lime.ui.Gamepad-Gerät zurück.
Haxe 
import mklib.tools.GamepadHelper;

// Standard-Feedback (Spieler 1, 200ms)
GamepadHelper.vibrate(0);

// Starker Explosionstreffer (Tiefer Motor 1.0, Hoher Motor 0.2, 400ms)
GamepadHelper.vibrate(0, 1.0, 0.2, 400);

// Vibration bei allen verbundenen Controllern
GamepadHelper.vibrateAll(0.7, 0.7, 250);

3. MathTool (mklib.math.MathTool)

Hilfsfunktion zur Rundung von Gleitkommazahlen auf feste Nachkommastellen:

Methode Signatur Rückgabe Beschreibung
floatFix (v:Float, length:Int):Float Float Rundet v auf length Nachkommastellen (z. B. MathTool.floatFix(3.1415, 2) == 3.14).

2. GamepadHelper (mklib.tools.GamepadHelper)

Helper class for triggering gamepad rumble and controller vibration via HaxeFlixel and Lime:

Method Signature Return Description
vibrate (gamepadID:Int = 0, lowFreq:Float = 0.5, highFreq:Float = 0.5, durationMs:Int = 200) Void Triggers controller vibration on the specified gamepad (low & high frequency motors in ms).
rumble (gamepadID:Int = 0, lowFreq:Float = 0.5, highFreq:Float = 0.5, durationMs:Int = 200) Void Direct inline alias for vibrate().
stopVibration (gamepadID:Int = 0) Void Stops vibration on the specified gamepad immediately.
vibrateAll (lowFreq:Float = 0.5, highFreq:Float = 0.5, durationMs:Int = 200) Void Triggers vibration on all currently connected gamepads.
stopAllVibrations () Void Stops all active vibrations on all gamepads.
getLimeGamepad (gamepadID:Int = 0) LimeGamepad Returns the native lime.ui.Gamepad device instance.
Haxe 
import mklib.tools.GamepadHelper;

// Default haptic feedback (Player 1, 200ms)
GamepadHelper.vibrate(0);

// Heavy impact / explosion (Low motor 1.0, High motor 0.2, 400ms)
GamepadHelper.vibrate(0, 1.0, 0.2, 400);

// Rumble all connected controllers
GamepadHelper.vibrateAll(0.7, 0.7, 250);

3. MathTool (mklib.math.MathTool)

Utility functions for rounding floating point numbers to fixed decimal places:

Method Signature Return Description
floatFix (v:Float, length:Int):Float Float Rounds v to length decimal places (e.g. MathTool.floatFix(3.1415, 2) == 3.14).
