👾 Entities & Sprites (mklib.entity.*)

Basisklassen für visuelle und physikalische Spielobjekte.

1. EntitySprite (mklib.entity.EntitySprite)

Basisklasse für rein visuelle Entities ohne Physik. Erbt von flixel.FlxSprite.

Eigenschaften

Eigenschaft Typ Modifizierer Beschreibung
_entity ldtk.Entity public Die originale LDtk-Entity-Definition inklusive benutzerdefinierter Felder.
iid String public Die weltweit eindeutige Instanz-ID der Entity aus LDtk.
state mklib.state.State public Referenz auf den aktuellen `State`.
graphicPath Null<String> public Der aufgelöste Pfad zur Grafikdatei (beginnend mit assets/, z. B. assets/tilesets/Fire.png), falls ein Tile zugewiesen ist, sonst null.
hasGraphic Bool public Gibt an, ob der Entity in LDtk eine gültige Grafikdatei zugewiesen ist (true), andernfalls false.

Methoden

Methode Signatur Rückgabe Beschreibung
new (entity:ldtk.Entity) Void Erstellt das Sprite, setzt Position, Abmessungen, bindet den State, initialisiert graphicPath / hasGraphic und lädt automatisch die Kachelgrafik, falls vorhanden.
getGraphicPath ():Null<String> Null<String> Ermittelt und normalisiert den Pfad zur Grafikdatei (beginnend mit assets/), falls ein Tile in LDtk definiert ist, und setzt hasGraphic.
getField (identifier:String):Dynamic Dynamic Liest den Wert eines benutzerdefinierten LDtk-Feldes (fieldInstances) aus oder null.
hasField (identifier:String):Bool Bool Prüft, ob ein benutzerdefiniertes LDtk-Feld für diese Entity existiert.
initAnimation (?animKey:String):Void Void Lädt alle Animationsclips aus AnimationRegistry.db und startet die Standardanimation.
createShapesFromGraphic (alphaThreshold:Int = 128, simplify:Float = 1.0, sensor:Bool = false, ?cbType:CbType, clearExisting:Bool = true, cellSizeVal:Float = 1.0):Array<Polygon> Array<Polygon> Erzeugt Nape-Polygon-Shapes vollautomatisch aus der sichtbaren Pixelgrafik des Sprites via Marching Squares.
resolvePixelCollision (obstacle:flixel.FlxSprite):Bool Bool Löst eine pixelgenaue Überlappung (FlxG.pixelPerfectOverlap) verzögerungsfrei auf (Positionskorrektur, Geschwindigkeitsstopp, Wall-Sliding). Gibt true zurück, wenn eine Kollision vorlag.
isPixelBlocked (dirX:Float, dirY:Float):Bool Bool Prüft vorausschauend, ob eine Bewegung in die angegebene Richtung zu einer Pixel-Überlappung mit lastCollidedObstacle führen würde.
onPositionCorrected ():Void Void Callback-Hook nach einer Positionskorrektur durch resolvePixelCollision (kann in Unterklassen überschrieben werden).
getFromInteractor (interactor:nape.phys.Interactor):Null<EntityNapeSprite> Null<EntityNapeSprite> Statische Hilfsmethode: Ermittelt die EntityNapeSprite-Instanz aus einem Nape-Interactor (Shape oder Body).

2. EntityNapeSprite (mklib.entity.EntityNapeSprite)

Erweiterte Basisklasse für Nape-Physik-Objekte. Erbt von flixel.addons.nape.FlxNapeSprite.

Eigenschaften

Eigenschaft Typ Modifizierer Beschreibung
_entity ldtk.Entity public Die zugrundeliegende LDtk-Entity mit allen Feldern.
iid String public Die eindeutige LDtk-Instanz-ID.
state mklib.state.State public Referenz auf den aktiven `State`.
graphicPath Null<String> public Der aufgelöste Pfad zur Grafikdatei (beginnend mit assets/), falls ein Tile zugewiesen ist, sonst null.
hasGraphic Bool public Gibt an, ob der Entity in LDtk eine gültige Grafikdatei zugewiesen ist (true), andernfalls false.
body nape.phys.Body public *(Ererbt)* Der physikalische Nape-Körper.
prevBodyX / prevBodyY Float public Nape-Körperposition vor dem aktuellen Physik-Schritt.
lastCollidedObstacle Null<flixel.FlxSprite> public Zuletzt berührtes Hindernis für vorausschauende Pixel-Blockade-Prüfungen (isPixelBlocked).
facingX / facingY Int public Aktuelle diskrete Blickrichtung der Entity (-1, 0, 1).
gridSize Int public Standard-Rastergröße für Gitterabfragen in Pixeln (Standard: 8).
recoilTimer Float public Verbleibende Rückstoß-Dauer (Recoil / Knockback) in Sekunden.
recoilVx / recoilVy Float public Aktuelle Rückstoß-Geschwindigkeit in X- bzw. Y-Richtung.

Methoden

Methode Signatur Rückgabe Beschreibung

resolveTilesetPath (tilesetUid:Int):Null<String> Null<String> Löst den relativen Asset-Pfad einer Tileset-Grafik anhand ihrer UID im LDtk-Projekt auf.

getGraphicPath ():Null<String> Null<String> Ermittelt und normalisiert den Pfad zur Grafikdatei (beginnend mit assets/), falls ein Tile oder TileRect in LDtk definiert ist.

hasField (identifier:String):Bool Bool Prüft, ob ein benutzerdefiniertes LDtk-Feld für diese Entity existiert.

updateShapePosition ():Void Void Zentriert den Nape-Körper im Mittelpunkt der Entity- bzw. Sprite-Maße (pixelX + width/2, pixelY + height/2).

applyRecoil (dirX:Float, dirY:Float, speed:Float = 65, duration:Float = 0.12):Void Void Löst einen physikalischen Rückstoß-Impuls (Recoil / Knockback / Zelda-Bounce) in die angegebene Richtung aus.
isRecoiling ():Bool Bool Gibt an, ob sich die Entity aktuell in einer aktiven Rückstoß-Phase befindet (recoilTimer > 0).
getGridX (gSize:Int = -1, offsetX:Float = 0):Int Int Berechnet die diskrete Raster-Spalte (X) auf Basis der Körperposition und eines optionalen Offsets.
getGridY (gSize:Int = -1, offsetY:Float = 0):Int Int Berechnet die diskrete Raster-Zeile (Y) auf Basis der Körperposition und eines optionalen Fußpunkt-Offsets.
getActiveState ():Null<State<Dynamic>> Null<State<Dynamic>> Liefert dynamisch und sicher die aktive State-Instanz aus der Instanz-Referenz oder FlxG.state.
hasEntityAtGrid (cx:Int, cy:Int, ?tags:Dynamic, ?entityClass:Class<Dynamic>, gSize:Int = -1):Bool Bool Prüft, ob sich in der Rasterzelle (cx, cy) eine Entity mit bestimmtem Tag (String oder Array, z. B. ["Obstacle", "Platform", "Wall", "Solid"]) oder Klassentyp befindet.
hasObstacleInFacingCell (dirX:Int = 0, dirY:Int = 0, ?tags:Dynamic, gSize:Int = -1, footOffsetY:Float = 0):Bool Bool Prüft, ob die Nachbarzelle in Blickrichtung durch ein Hindernis oder eine Wand (prüft standardmäßig ["Obstacle", "Platform", "Wall", "Solid"]) belegt ist.
createShapesFromGraphic (alphaThreshold:Int = 128, simplify:Float = 1.0, sensor:Bool = false, ?cbType:CbType, clearExisting:Bool = true, cellSizeVal:Float = 1.0):Array<Polygon> Array<Polygon> Erzeugt Nape-Polygon-Shapes vollautomatisch aus der sichtbaren Pixelgrafik des Sprites via Marching Squares.
resolvePixelCollision (obstacle:flixel.FlxSprite):Bool Bool Löst eine pixelgenaue Überlappung (FlxG.pixelPerfectOverlap) verzögerungsfrei auf (Positionskorrektur, Geschwindigkeitsstopp, Wall-Sliding). Gibt true zurück, wenn eine Kollision vorlag.
isPixelBlocked (dirX:Float, dirY:Float):Bool Bool Prüft vorausschauend, ob eine Bewegung in die angegebene Richtung zu einer Pixel-Überlappung mit lastCollidedObstacle führen würde.
onPositionCorrected ():Void Void Callback-Hook nach einer Positionskorrektur durch resolvePixelCollision (kann in Unterklassen überschrieben werden).
getFromInteractor (interactor:nape.phys.Interactor):Null<EntityNapeSprite> Null<EntityNapeSprite> Statische Hilfsmethode: Ermittelt die EntityNapeSprite-Instanz aus einem Nape-Interactor (Shape oder Body).

2. EntityNapeSprite (mklib.entity.EntityNapeSprite)

Erweiterte Basisklasse für Nape-Physik-Objekte. Erbt von flixel.addons.nape.FlxNapeSprite.

Properties

Property Type Modifier Description
_entity ldtk.Entity public Die zugrundeliegende LDtk-Entity mit allen Feldern.
iid String public Die eindeutige LDtk-Instanz-ID.
state mklib.state.State public Referenz auf den aktiven `State`.
graphicPath Null<String> public Der aufgelöste Pfad zur Grafikdatei (beginnend mit assets/), falls ein Tile zugewiesen ist, sonst null.
hasGraphic Bool public Gibt an, ob der Entity in LDtk eine gültige Grafikdatei zugewiesen ist (true), andernfalls false.

facingX / facingY Int public Current discrete facing direction of the entity (-1, 0, 1).

recoilTimer Float public Remaining recoil / knockback duration in seconds.
recoilVx / recoilVy Float public Current recoil velocity along X or Y axis.

Methods

Method Signature Rückgabe Description
new (entity:ldtk.Entity) Void Creates the Nape sprite. If a non-null TileRect field is present, loads the tileset crop, adjusts size, creates a static Nape body (BodyType.STATIC), and optionally configures it as a sensor.
resolveTilesetPath (tilesetUid:Int):Null<String> Null<String> Resolves the relative asset path for a tileset graphic based on its UID in the LDtk project.
loadTileRectGraphic (path:String, tileX:Int, tileY:Int, tileW:Int, tileH:Int):Void Void Crops the specified region from the tileset texture, caches it in FlxG.bitmap, and assigns it to the sprite.
getGraphicPath ():Null<String> Null<String> Resolves and normalizes the path to the graphic file (starting with assets/), if a tile or TileRect is defined in LDtk.
getField (identifier:String):Dynamic Dynamic Reads the value of a custom LDtk field (fieldInstances) or null.
hasField (identifier:String):Bool Bool Checks if a custom LDtk field exists for this entity.
sensorEnabled (?enable:Null<Bool>):Void Void Sets the sensorEnabled property for all shapes of the body. Without parameters, reads the value from the LDtk field "sensor" or "sensorEnabled".
addCbType (name:String = null):Void Void Assigns tags to the Nape body. Automatically reads LDtk fields "Tag" or "Tags" if name == null. Sets body.userData.instance = this.
updateShapePosition ():Void Void Centers the Nape body on the entity / sprite center (pixelX + width/2, pixelY + height/2).
initAnimation (?animKey:String):Void Void Loads all animation clips from AnimationRegistry.db and starts the default animation.
applyRecoil (dirX:Float, dirY:Float, speed:Float = 65, duration:Float = 0.12):Void Void Triggers a physical recoil / knockback impulse in the specified direction.
isRecoiling ():Bool Bool Returns whether the entity is currently in an active recoil phase (recoilTimer > 0).
getGridX (gSize:Int = -1, offsetX:Float = 0):Int Int Calculates the discrete raster column (X) from the body position and optional offset.
getGridY (gSize:Int = -1, offsetY:Float = 0):Int Int Calculates the discrete raster row (Y) from the body position and optional foot offset.
getActiveState ():Null<State<Dynamic>> Null<State<Dynamic>> Dynamically and safely resolves the active State instance from the reference or FlxG.state.
hasEntityAtGrid (cx:Int, cy:Int, ?tags:Dynamic, ?entityClass:Class<Dynamic>, gSize:Int = -1):Bool Bool Checks if a specific entity tag (string or array, e.g. ["Obstacle", "Platform", "Wall", "Solid"]) or class occupies the raster grid cell (cx, cy).
hasObstacleInFacingCell (dirX:Int = 0, dirY:Int = 0, ?tags:Dynamic, gSize:Int = -1, footOffsetY:Float = 0):Bool Bool Checks whether the neighbor cell in the facing direction contains an obstacle or wall (defaults to ["Obstacle", "Platform", "Wall", "Solid"]).
createShapesFromGraphic (alphaThreshold:Int = 128, simplify:Float = 1.0, sensor:Bool = false, ?cbType:CbType, clearExisting:Bool = true, cellSizeVal:Float = 1.0):Array<Polygon> Array<Polygon> Generates Nape polygon shapes automatically from visible graphic pixels via Marching Squares.
resolvePixelCollision (obstacle:flixel.FlxSprite):Bool Bool Resolves pixel-perfect overlap (FlxG.pixelPerfectOverlap) with zero latency (position correction, velocity stop, wall-sliding). Returns true if collision occurred.
isPixelBlocked (dirX:Float, dirY:Float):Bool Bool Checks predictively whether movement in the specified direction would cause pixel overlap with lastCollidedObstacle.
onPositionCorrected ():Void Void Callback hook invoked after position correction by resolvePixelCollision (can be overridden in subclasses).
getFromInteractor (interactor:nape.phys.Interactor):Null<EntityNapeSprite> Null<EntityNapeSprite> Static helper: Retrieves the EntityNapeSprite instance from a Nape interactor (shape or body).
