🎮 State Management (mklib.state.State)

Die generische Basisklasse für HaxeFlixel-Spielzustände mit automatischer LDtk- und Nape-Anbindung.

Klassensignatur

Haxe Signature 
class State<TLevel = Dynamic> extends flixel.FlxState

Eigenschaften (Properties)

Eigenschaft Typ Modifizierer Beschreibung
project ldtk.Project public Die geladene LDtk-Projektinstanz (automatisch via Reflection aus Data oder per Parameter).
tags Map<String, nape.callbacks.CbType> public Map aller registrierten Nape-CbTypes, aufgelöst aus dem LDtk-Enum "Tags".
levelName String public Der Name des aktuell aktiven LDtk-Levels (z. B. "Level_0").
data TLevel public Die typisierten Leveldaten des geladenen Levels (z. B. data.l_Tiles, data.l_Entities).

Methoden (Methods)

Methode Signatur Rückgabe Beschreibung
new (LevelName:String = "Level_0", ?projectInstance:ldtk.Project) Void Erstellt den State, bindet das LDtk-Projekt und lädt das angegebene Level in data.
create ():Void Void Initialisiert den Spielzustand (ruft super.create() auf).
napeInit (gx:Int, gy:Int):Void Void Initialisiert FlxNapeSpace, setzt die globale Schwerkraft und ruft automatisch addCbTypes() auf.
addCbTypes ():Void Void Liest das LDtk-Enum "Tags" aus der Projektdefinition aus und füllt die tags-Map mit CbType-Instanzen.
update (elapsed:Float):Void Void Frame-Update-Schleife. Regelt u. a. die automatische Sichtbarkeit des Mauszeigers (Windows vs. HTML5).
