🧱 Layer System (mklib.layer.*)

Verwaltung und Darstellung von Kachel- und Entity-Ebenen aus LDtk.

1. TileLayer (mklib.layer.TileLayer)

Erbt von FlxSpriteGroup und rendert statische (Layer_Tiles) oder automatische Kachelebenen (Layer_AutoLayer).

Eigenschaften

Eigenschaft Typ Modifizierer Beschreibung
levelName String public Der Name des geladenen LDtk-Levels (z. B. "Level_0").
layerName String public Der Bezeichner des LDtk-Tile-Layers (z. B. "Tiles", "Background").
state mklib.state.State public Referenz auf den aktiven `State`.

Methoden

Methode Signatur Rückgabe Beschreibung
new (LayerName:String) Void Erstellt den TileLayer, bindet State/Level und führt direkt render() aus.
render ():FlxSpriteGroup FlxSpriteGroup Leert die Gruppe und zeichnet die Kacheln anhand von state.data neu. Gibt this zurück.

2. EntityLayer & EntityLayerSource

Erbt von FlxSpriteGroup und instanziiert automatisch alle LDtk-Entities via Reflection.

Typedef: EntityLayerSource<T = Dynamic>

Feld Typ Beschreibung
identifier String Der Bezeichner des Layers in LDtk (z. B. "Entities", "Actors").
getAllUntyped () -> Array<T> Gibt alle im Layer platzierten Entities als Array zurück.

Eigenschaften von EntityLayer

Eigenschaft Typ Modifizierer Beschreibung
layerName String public Der LDtk-Layer-Bezeichner.
packageName String public Das Haxe-Package zur Klassensuche (Standard: "entities").
state mklib.state.State<Dynamic> public Referenz auf den aktiven `State`.

Methoden von EntityLayer

Methode Signatur Rückgabe Beschreibung
new (layer:EntityLayerSource<Dynamic>, packageName:String = "entities") Void Erstellt den Layer, liest alle Entities aus und ruft addEntities() auf.
addEntities (entities:Array<ldtk.Entity>):Void Void Instanziiert dynamisch passende Klassen (packageName.EntityIdentifier) oder nutzt Fallback auf EntityNapeSprite / EntitySprite.
isNapeEntity (entity:ldtk.Entity):Bool Bool Prüft, ob eine Entity Nape-Physikeigenschaften (Felder wie Tag, sensorEnabled oder LDtk-Tags) aufweist.
