🧭 Pathfinding & A* (mklib.path.*)

Performante 2D A*-Wegfindung für 4- und 8-Wege-Bewegung sowie Multi-Tile-Einheiten.

⚡ Interaktiver Live-A*-Simulator

Start (S) ziehen
Ziel (Z) ziehen
Klick & Ziehen = Wand zeichnen/löschen
Gefundener A*-Pfad

1. NavGrid (mklib.path.NavGrid)

Speichert das 2D-Raster in einem flachen 1D-Array (0 = frei, 1 = blockiert).

Eigenschaften

Eigenschaft Typ Modifizierer Beschreibung
width Int public (default, null) Breite des Rasters in Zellen (Spalten).
height Int public (default, null) Höhe des Rasters in Zellen (Zeilen).
gridSize Int public (default, null) Kantenlänge einer Zelle in Pixeln (z. B. 16).
data Array<Int> public Lineares 1D-Array aller Zellen (Größe width * height).

Methoden

Methode Signatur Rückgabe Beschreibung
new (w:Int, h:Int, gridSize:Int = 16, defaultValue:Int = 0) Void Erstellt ein neues NavGrid.
isInBounds (cx:Int, cy:Int):Bool Bool Prüft, ob (cx, cy) innerhalb der Map-Grenzen liegt.
getIndex (cx:Int, cy:Int):Int Int Berechnet (cy * width) + cx.
get (cx:Int, cy:Int):Int Int Gibt den Zellwert zurück (oder 1 außerhalb).
set (cx:Int, cy:Int, value:Int):Void Void Setzt den Wert einer Zelle.
isWalkable (cx:Int, cy:Int):Bool Bool Prüft, ob eine Zelle frei ist (value == 0).
isAreaWalkable (cx:Int, cy:Int, spanX:Int = 1, spanY:Int = 1):Bool Bool Prüft einen ganzen Bereich für Multi-Tile-Einheiten.
setArea (cx:Int, cy:Int, spanX:Int, spanY:Int, value:Int = 1):Void Void Setzt einen rechteckigen Bereich auf value.
setEntity (entity:ldtk.Entity, value:Int = 1):Void Void Blockiert die Fläche einer LDtk-Entity anhand ihrer Pixelmaße.
worldToGridX (worldX:Float):Int Int Konvertiert Pixel-X in Raster-X.
worldToGridY (worldY:Float):Int Int Konvertiert Pixel-Y in Raster-Y.
gridToWorldX (cx:Int, centered:Bool = false):Float Float Konvertiert Raster-X in Pixel-X (optional mit Zentrierung).
gridToWorldY (cy:Int, centered:Bool = false):Float Float Konvertiert Raster-Y in Pixel-Y (optional mit Zentrierung).
clear (value:Int = 0):Void Void Setzt alle Zellen auf value zurück.
clone ():NavGrid NavGrid Erstellt eine tiefe Kopie des Grids.
toString ():String String Gibt eine ASCII-Vorschau des Grids zurück.

2. NavGridBuilder (mklib.path.NavGridBuilder)

Fluent Builder zum automatischen Extrahieren von Hindernissen aus LDtk-Leveln.

Methode Signatur Rückgabe Beschreibung
new (w:Int, h:Int, gridSize:Int = 16, defaultValue:Int = 0) Void Erstellt einen Builder mit festen Maßen.
fromLevel (levelObj:Dynamic, defaultGridSize:Int = 16) NavGridBuilder Erstellt Builder aus LDtk-Levelobjekt.
addIntGrid (layer:Dynamic, ?isSolid:(val:Int)->Bool) NavGridBuilder Fügt IntGrid-Layer hinzu.
addTileLayer (layer:Dynamic, ?isSolid:(tileId:Int)->Bool) NavGridBuilder Fügt Tile- oder AutoLayer hinzu.
addEntityLayer (layer:Dynamic, ?filter:(e:ldtk.Entity)->Bool) NavGridBuilder Fügt Entity-Layer hinzu.
addLayerByName (name:String, ?isSolidEntity:(e:ldtk.Entity)->Bool) NavGridBuilder Löst Layer nach Name auf.
autoBuild (levelObj:Dynamic, ?isSolidEntity:(e:ldtk.Entity)->Bool, defaultGridSize:Int = 16) NavGrid Scannt alle Layer automatisch und baut das Grid fertig.
build ():NavGrid NavGrid Liefert das konfigurierte `NavGrid` zurück.

GridPoint

Element Typ / Signatur Beschreibung

new (x:Int, y:Int) (Methode) Erstellt einen neuen Punkt.

AStar
