💡 GPU-Shader-Lighting-System (mklib.light.*)

Hardwarebeschleunigte 2D-Echtzeitbeleuchtung auf GPU-Shader-Basis mit Viewport-Culling, 5 Licht-Typen und nativer LDtk Custom-Properties-Steuerung.

🌟 Features & Highlights

  • ⚡ GLSL-Shader auf der GPU: Berechnet bis zu 32 dynamische Lichter gleichzeitig in einem einzigen Render-Pass mit sanften Hermite-Dämpfungskurven (smoothstep).
  • 🎯 5 Spezialisierte Licht-Typen:
    • PointLight: 360°-Rundumlicht mit anpassbarem 100%-Helligkeitskern (innerRadius).
    • SpotLight: Gerichteter Scheinwerfer mit Abstrahlwinkel, Gesamtkegel und weichem Fokusübergang (innerAngle).
    • TorchLight: Naturgetreues Fackelflackern durch multi-harmonische Wellen und Flammen-Wobble (flameJitter).
    • GlowLight: Sanft atmendes Magie-/Aura-Licht mit konfigurierbaren Min/Max-Bereichen und Puls-Geschwindigkeit.
    • DirectionalLight: Globales Sonnen-, Mond- und Umgebungslicht mit Einfallswinkel.
  • 🚀 Automatisches Frustum-Culling: In großen Welten werden pro Frame nur die aktuell im Kamerabereich sichtbaren Lichter an die GPU gesendet.
  • 🧲 Zielverfolgung (follow): Lichter folgen Spielfiguren oder Objekten automatisch mit konfigurierbarem Versatz.
  • 🗺️ Volle LDtk-Integration: Alle Lichteigenschaften können direkt in LDtk als Custom Fields definiert und automatisiert geladen werden.

🚀 Code-Beispiele

1. Grundlegendes Setup im PlayState

Haxe 
package;

import mklib.state.State;
import mklib.light.LightingSystem;

class PlayState extends State<Data.Data_Level> {
    public var lighting:LightingSystem;

    override public function create():Void {
        super.create();

        // 1. LightingSystem mit dunkler Nacht-Atmosphäre erstellen (Overlay-Sprite)
        lighting = new LightingSystem(0xFF141424, 0.2);

        // 2. Fackellicht erzeugen
        var torch = lighting.createTorchLight(100, 100, 120, 0xFFFFAA44, 1.0);

        // 3. Scheinwerfer erzeugen
        var spot = lighting.createSpotLight(200, 80, 160, 90, 45, 0xFFFFFFFF);

        // 4. Pulsierenden Kristall erzeugen
        var glow = lighting.createGlowLight(350, 120, 30, 70, 0xFF55AAFF, 0.3, 1.0, 2.0);

        // 5. Zum State hinzufügen
        add(lighting);
    }
}

2. Licht an Spielfigur binden

Haxe 
// Fackel folgt der Spielerfigur automatisch
var playerLight = lighting.createTorchLight(0, 0, 120, 0xFFFF9933, 1.0);
playerLight.follow(heroSprite, 0, 0, true);

3. Scheinwerfer auf Ziel ausrichten

Haxe 
// In der update()-Schleife: Scheinwerfer folgt der Maus oder einem Objekt
spot.pointAt(FlxG.mouse.x, FlxG.mouse.y);
// oder:
spot.lookAt(targetEnemy);

🗺️ LDtk Custom-Properties (Editor-Steuerung)

Lichter können komplett im LDtk-Editor über benutzerdefinierte Entity-Felder (Custom Fields) konfiguriert werden. LightingSystem.loadFromLevel(data) liest alle Licht-Entities automatisch ein:

LDtk-Feldname Typ Betroffene Lichter Beschreibung & Standardwert
type / light_type String / Enum Alle "point", "spot", "torch", "glow", "directional" (Fallback: Entity-Identifier).
radius / light_radius Float / Int Alle Lichtradius in Pixeln (Standard: 100.0).
color / light_color Color / Int / Hex Alle Lichtfarbe (Standard: Weiß 0xFFFFFFFF bzw. Fackel 0xFFFFAA44).
intensity / light_intensity Float Alle Helligkeit (Standard: 1.0).
falloff / light_falloff Float Alle Dämpfungsexponent (Standard: 1.0 für weiche Kante).
innerRadius Float PointLight Radius für 100% Leuchtkraft vor Beginn des Helligkeitsabfalls (Standard: 0.0).
angle / direction Float SpotLight, Directional Abstrahlwinkel in Grad (0° = rechts, 90° = unten, Standard: 0.0).
spotAngle / coneAngle Float SpotLight Gesamtöffnungswinkel des Strahls in Grad (Standard: 45.0).
innerAngle Float SpotLight Innerer Fokuswinkel für sanfte Strahlränder (Standard: 15.0).
flickerSpeed / speed Float TorchLight Frequenz des Flackerns in Hz (Standard: 8.0).
flickerIntensity Float TorchLight Helligkeits-Schwankung der Flamme (Standard: 0.15).
flickerRadius Float TorchLight Radius-Schwankung in Pixeln (Standard: 10.0).
flameJitter Float TorchLight Docht-Wobble / Flammenverschiebung in Pixeln (Standard: 2.0).
minRadius / maxRadius Float GlowLight Minimaler und maximaler Radius beim Pulsieren.
minIntensity / maxIntensity Float GlowLight Minimale und maximale Helligkeit beim Pulsieren.
pulseSpeed Float GlowLight Geschwindigkeit des Pulsierens (Standard: 2.0).
active / enabled Bool Alle Ob das Licht initial aktiv ist (Standard: true).
offsetX / offsetY Float Alle Versatz relativ zur Entity (Standard: Entity-Zentrum).

🏛️ Detaillierte API-Referenz

1. LightingSystem (mklib.light.LightingSystem)

Element Typ / Signatur Beschreibung
ambientColor FlxColor (Standard: 0xFF141424) Grundfarbe der Umgebung / Dunkelheit.
ambientIntensity Float (Standard: 0.2) Grundhelligkeit der Umgebung (0.0 = stockdunkel, 1.0 = voll ausgeleuchtet).
autoCull Bool (Standard: true) Aktiviert automatisches Frustum-Culling für maximale GPU-Performance.
lights Array<Light> Liste aller registrierten Lichter.
addLight <T:Light>(light:T):T Registriert ein Licht im System.
removeLight <T:Light>(light:T, destroy:Bool = false):T Entfernt ein Licht aus dem System.
createPointLight (x, y, radius, color, intensity, innerRadius, falloff):PointLight Erzeugt und registriert ein Punktlicht.
createSpotLight (x, y, radius, angle, spotAngle, color, intensity, innerAngle, falloff):SpotLight Erzeugt und registriert einen Scheinwerfer.
createTorchLight (x, y, radius, color, intensity, flickerSpeed, flickerIntensity, flickerRadius, flameJitter):TorchLight Erzeugt und registriert eine flackernde Fackel.
createGlowLight (x, y, minRadius, maxRadius, color, minIntensity, maxIntensity, pulseSpeed, pulsePhase):GlowLight Erzeugt und registriert ein pulsierendes Magielicht.
createDirectionalLight (directionAngle, color, intensity):DirectionalLight Erzeugt und registriert ein globales Sonnen-/Mondlicht.
loadFromLevel (levelData:Dynamic):Int Lädt alle Licht-Entities aus einem LDtk-Level automatisch.
fromEntity (entity:ldtk.Entity):Null<Light> Parst eine LDtk-Entity anhand ihrer Custom-Properties.

2. Light Basisklasse (mklib.light.Light)

Element Typ / Signatur Beschreibung
x, y Float Weltkoordinaten der Lichtquelle in Pixeln.
radius Float Radius des Lichts in Pixeln.
color FlxColor Farbe des Lichts.
intensity Float Helligkeits-Multiplikator (1.0 = Standard).
falloff Float Dämpfungsexponent (1.0 = sanfter Standardabfall).
active / visible Bool Aktivierungs- und Sichtbarkeitsstatus.
follow (target:FlxObject, offsetX:Float = 0, offsetY:Float = 0, center:Bool = true):Light Bindet das Licht an ein Spielobjekt / Sprite.
stopFollowing ():Light Löst die Bindung an das Zielobjekt.
setPosition (x:Float, y:Float):Light Setzt die Weltposition manuell.
setColor (color:FlxColor, ?intensity:Float):Light Setzt Farbe und optionale Intensität.
