⚡ Physik & Sensoren (mklib.physic.* & mklib.tools.Tags)

Einfache Registrierung von Kollisionen und Sensor-Überlappungen ohne manuelle CbType-Verwaltung.

1. Tags (mklib.tools.Tags)

Statische Hilfsklasse zum Abfragen von CbType-Objekten aus dem aktuellen `State`.

Methode Signatur Rückgabe Beschreibung
get (tag:String):nape.callbacks.CbType CbType Gibt den registrierten CbType für einen Tag-Namen zurück (oder null).
exist (tag:String):Bool Bool Prüft, ob der Tag im aktuellen State registriert ist.

2. Listener (mklib.physic.Listener)

Statische Methoden zur Registrierung aller Kollisions- und Sensor-Events.

Physische Kollisionen (InteractionType.COLLISION)

Methode Signatur Ereignis Beschreibung
addCollisionBeginListener (t1:String, t2:String, handler:InteractionCallback->Void) CbEvent.BEGIN Wird aufgerufen, sobald sich zwei Körper mit t1 und t2 berühren.
addCollisionEndListener (t1:String, t2:String, handler:InteractionCallback->Void) CbEvent.END Wird aufgerufen, sobald der Kontakt zwischen t1 und t2 abreißt.
addCollisionOngoingListener (t1:String, t2:String, handler:InteractionCallback->Void) CbEvent.ONGOING Wird in jedem Physik-Tick aufgerufen, solange t1 und t2 in Kontakt stehen.

Sensor-Überlappungen (InteractionType.SENSOR)

Methode Signatur Ereignis Beschreibung
addSensorBeginListener (t1:String, t2:String, handler:InteractionCallback->Void) CbEvent.BEGIN Überlappung zwischen t1 und t2 beginnt.
addSensorEndListener (t1:String, t2:String, handler:InteractionCallback->Void) CbEvent.END Überlappung zwischen t1 und t2 endet.
addSensorOngoingListener (t1:String, t2:String, handler:InteractionCallback->Void) CbEvent.ONGOING Überlappung zwischen t1 und t2 dauert an.
addSensorBeginListenerANY (t1:String, handler:InteractionCallback->Void) CbEvent.BEGIN t1 überlappt mit beliebigem anderen Körper (CbType.ANY_BODY).
addSensorEndListenerANY (t1:String, handler:InteractionCallback->Void) CbEvent.END t1 verlässt Überlappung mit beliebigem anderen Körper.
addSensorOngoingListenerANY (t1:String, handler:InteractionCallback->Void) CbEvent.ONGOING t1 überlappt andauernd mit beliebigem anderen Körper.

Pixelgenaue Kollisionen (Pixel-Perfect Collision)

Pixelgenaue Kollisionsüberwachung via FlxG.pixelPerfectOverlap mit automatischer Positionskorrektur, Geschwindigkeitsstopp und Wall-Sliding über EntityNapeSprite.resolvePixelCollision.

Methode Signatur Ereignis Beschreibung
addPixelCollisionListener (tag1:String, tag2:String, ?onCollision:EntityNapeSprite->EntityNapeSprite->Void) CbEvent.ONGOING (Sensor) + Pixel-Overlap Physische Pixel-Kollision: Registriert eine pixelgenaue Kollisionsüberwachung zwischen tag1 (Akteur) und tag2 (Hindernis). Löst bei Pixel-Überlappung automatisches Zurücksetzen, Stoppen und Wall-Sliding via resolvePixelCollision aus. Optionaler Callback (actor, obstacle) -> Void.
addPixelSensorBeginListener (tag1:String, tag2:String, onBegin:EntityNapeSprite->EntityNapeSprite->Void) CbEvent.BEGIN (Pixel) Pixel-Sensor (Start): Feuert genau einmal im ersten Frame, in dem sich tatsächliche Pixel von tag1 und tag2 berühren (ohne physikalischen Widerstand). Ideal für Münzen, Power-Ups, Schalter.
addPixelSensorOngoingListener (tag1:String, tag2:String, onOngoing:EntityNapeSprite->EntityNapeSprite->Void) CbEvent.ONGOING (Pixel) Pixel-Sensor (Dauerhaft): Feuert in jedem Physik-Tick, solange tatsächliche Pixel überlappen (z. B. Schaden über Zeit in Giftwolken/Lava, Wasserströmungen).
addPixelSensorEndListener (tag1:String, tag2:String, onEnd:EntityNapeSprite->EntityNapeSprite->Void) CbEvent.END (Pixel) Pixel-Sensor (Ende): Feuert in dem Frame, in dem die Pixel-Überlappung abreißt, nachdem zuvor ein Kontakt bestand (z. B. Verlassen von Bereichen).

3. ShapeBuilder (mklib.physic.ShapeBuilder)

Statische Hilfsklasse zur automatischen Generierung konvexer Nape-Polygon-Shapes direkt aus Pixelgrafiken (BitmapData / FlxSprite) mittels Marching Squares und Polygonzerlegung.

Methode Signatur Rückgabe Beschreibung
createShapesFromBitmap (bmd:BitmapData, ?body:Body, alphaThreshold:Int = 128, simplify:Float = 1.0, ?offset:Vec2, sensor:Bool = false, ?cbType:CbType, cellSizeVal:Float = 1.0) Array<Polygon> Erzeugt konvexe Nape-Polygon-Shapes direkt aus den sichtbaren Pixeln einer BitmapData.
createShapesFromSprite (sprite:FlxSprite, ?body:Body, alphaThreshold:Int = 128, simplify:Float = 1.0, sensor:Bool = false, ?cbType:CbType, cellSizeVal:Float = 1.0) Array<Polygon> Erzeugt passgenaue Polygon-Shapes für ein FlxSprite unter Berücksichtigung von origin.x/y.
createBodyFromSprite (sprite:FlxSprite, ?type:BodyType, alphaThreshold:Int = 128, simplify:Float = 1.0, sensor:Bool = false, ?cbType:CbType, cellSizeVal:Float = 1.0) Body Erzeugt einen neuen Nape-Body (STATIC, DYNAMIC, KINEMATIC) bestückt mit den Polygon-Shapes des Sprites.
extractFrameBitmap (sourceBmd:BitmapData, frameRect:Rectangle, flipX:Bool = false, flipY:Bool = false) Null<BitmapData> Schneidet ein einzelnes Frame aus einer Spritesheet-Grafik aus (inkl. optionalem FlipX / FlipY).
createShapesForAnimation (sprite:FlxSprite, animName:String, alphaThreshold:Int = 128, simplify:Float = 1.0, sensor:Bool = true, ?cbType:CbType, cellSizeVal:Float = 1.0) Map<String, Array<Polygon>> Erzeugt vorberechnete Polygon-Shapes für alle Frames einer Animation (Normal & gespiegelt) mit userData-Metadaten.
Haxe 
import mklib.physic.ShapeBuilder;
import mklib.tools.Tags;
import nape.phys.BodyType;

// 1. Shapes direkt aus Sprite generieren und dem Body zuweisen
var shapes = ShapeBuilder.createShapesFromSprite(
    mySprite,
    myBody,
    128,                  // Alpha-Schwellenwert
    1.0,                  // Glättung / Vereinfachung
    false,                // Sensor
    Tags.get("Obstacle")  // Kollisions-Tag
);

// 2. Oder kompletten Nape-Body direkt aus einem Sprite bauen
var dynamicBody = ShapeBuilder.createBodyFromSprite(
    enemySprite,
    BodyType.DYNAMIC,
    128,
    1.5,
    false,
    Tags.get("Enemy")
);

Pixel-Perfect Collisions

Pixel-accurate collision detection via FlxG.pixelPerfectOverlap with automatic position correction, velocity stopping, and smooth wall-sliding via EntityNapeSprite.resolvePixelCollision.

Method Signature Event Description
addPixelCollisionListener (tag1:String, tag2:String, ?onCollision:EntityNapeSprite->EntityNapeSprite->Void) CbEvent.ONGOING (Sensor) + Pixel Overlap Physical Pixel Collision: Registers pixel-perfect collision detection between tag1 (moving actor) and tag2 (obstacle). Automatically handles positional reset, stopping, and wall-sliding via resolvePixelCollision. Optional callback (actor, obstacle) -> Void.
addPixelSensorBeginListener (tag1:String, tag2:String, onBegin:EntityNapeSprite->EntityNapeSprite->Void) CbEvent.BEGIN (Pixel) Pixel Sensor (Begin): Fires once in the exact frame when actual visible pixels of tag1 and tag2 touch (without blocking physical movement). Ideal for collectibles, triggers, switches.
addPixelSensorOngoingListener (tag1:String, tag2:String, onOngoing:EntityNapeSprite->EntityNapeSprite->Void) CbEvent.ONGOING (Pixel) Pixel Sensor (Ongoing): Fires every physics tick while visible pixels are overlapping (e.g. damage over time in hazards/lava, currents).
addPixelSensorEndListener (tag1:String, tag2:String, onEnd:EntityNapeSprite->EntityNapeSprite->Void) CbEvent.END (Pixel) Pixel Sensor (End): Fires in the frame when pixel overlap ceases after having previously overlapped (e.g. exiting zones).

3. ShapeBuilder (mklib.physic.ShapeBuilder)

Static utility for automated convex polygon shape generation directly from pixel graphics (BitmapData / FlxSprite) using Marching Squares and polygon decomposition.

Method Signature Return Description
createShapesFromBitmap (bmd:BitmapData, ?body:Body, alphaThreshold:Int = 128, simplify:Float = 1.0, ?offset:Vec2, sensor:Bool = false, ?cbType:CbType, cellSizeVal:Float = 1.0) Array<Polygon> Generates convex Nape polygon shapes directly from visible pixels of a BitmapData.
createShapesFromSprite (sprite:FlxSprite, ?body:Body, alphaThreshold:Int = 128, simplify:Float = 1.0, sensor:Bool = false, ?cbType:CbType, cellSizeVal:Float = 1.0) Array<Polygon> Generates tailored polygon shapes for an FlxSprite respecting origin offset.
createBodyFromSprite (sprite:FlxSprite, ?type:BodyType, alphaThreshold:Int = 128, simplify:Float = 1.0, sensor:Bool = false, ?cbType:CbType, cellSizeVal:Float = 1.0) Body Creates a new Nape Body (STATIC, DYNAMIC, KINEMATIC) populated with the sprite's polygon shapes.
extractFrameBitmap (sourceBmd:BitmapData, frameRect:Rectangle, flipX:Bool = false, flipY:Bool = false) Null<BitmapData> Extracts a single frame rectangle from a spritesheet graphic (with optional flipX / flipY).
createShapesForAnimation (sprite:FlxSprite, animName:String, alphaThreshold:Int = 128, simplify:Float = 1.0, sensor:Bool = true, ?cbType:CbType, cellSizeVal:Float = 1.0) Map<String, Array<Polygon>> Generates precalculated polygon shapes for all animation frames (normal & flipped) with userData tags.
Haxe 
import mklib.physic.ShapeBuilder;
import mklib.tools.Tags;
import nape.phys.BodyType;

// 1. Generate shapes from sprite and attach to body
var shapes = ShapeBuilder.createShapesFromSprite(
    mySprite,
    myBody,
    128,                  // Alpha threshold
    1.0,                  // Smoothing / simplification
    false,                // Sensor
    Tags.get("Obstacle")  // Collision tag
);

// 2. Or create an entire new Nape body directly from a sprite
var dynamicBody = ShapeBuilder.createBodyFromSprite(
    enemySprite,
    BodyType.DYNAMIC,
    128,
    1.5,
    false,
    Tags.get("Enemy")
);
