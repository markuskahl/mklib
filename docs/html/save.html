💾 Save- & Persistence-System (mklib.save.*)

Leichtgewichtiges, plattformübergreifendes Speichersystem mit Checkpoints, Multi-Level-Caching, Entity-IID-Tracking und optionaler Datenverschleierung.

🕹️

FlxSave Checkpoints

Plattformübergreifende Persistenz im LocalStorage oder auf der Festplatte via HaxeFlixel FlxSave.

🗺️

Multi-Level Caching

RAM-Session-Cache merkt sich Änderungen in allen besuchten Leveln bei Reisen durch offene Welten.

👾

Entity-IID Tracking

Zerstörte Münzen, Truhen oder Bosse werden beim erneuten Betreten des Levels automatisch gefiltert.

🔒

XOR / Base64 Schutz

Optionale Datenverschleierung zur Vermeidung von Manipulationen im LocalStorage oder Speicherstand.

2. ISaveable-Interface (mklib.save.ISaveable)

Interface für Entities oder Spielobjekte, deren individueller Zustand gespeichert werden soll:

Haxe 
package entities;

import mklib.entity.EntitySprite;
import mklib.save.ISaveable;

class Chest extends EntitySprite implements ISaveable {
    public var isOpened:Bool = false;

    public function saveState():Dynamic {
        return { isOpened: this.isOpened };
    }

    public function loadState(data:Dynamic):Void {
        if (data != null && data.isOpened != null) {
            this.isOpened = data.isOpened;
        }
    }
}

💾 Save & Persistence System (mklib.save.*)

Lightweight, cross-platform persistence system with checkpoints, multi-level caching, entity IID tracking, and optional data obfuscation.

🕹️

FlxSave Checkpoints

Cross-platform storage via HaxeFlixel FlxSave (LocalStorage / Desktop file system).

🗺️

Multi-Level Caching

In-memory session cache preserves changes across all visited levels during open-world exploration.

👾

Entity-IID Tracking

Destroyed items, coins, and defeated enemies are automatically filtered when revisiting levels.

🔒

XOR / Base64 Security

Optional payload obfuscation and checksum validation to prevent casual save tampering.

1. SaveManager (mklib.save.SaveManager)

Static facade for all save, load, session-cache, and checkpoint operations.

Properties

Property Type Modifier Description
config SaveConfig public static Configuration settings for save name, obfuscation, and salt.
playTime Float public static Accumulated play time in seconds.
globals Map<String, Dynamic> public static Global cross-level variables (inventory, flags, settings).
levelStates Map<String, LevelSaveState> public static RAM-cached states of all visited levels.
lastCheckpointMeta Null<CheckpointMeta> public static Metadata of the most recent saved or loaded checkpoint.

Methods

Method Signature Returns Description
saveCheckpoint (?customMeta:Dynamic, ?targetState:State<Dynamic>):Bool Bool Saves the complete game state (globals, active level, level-cache) to FlxSave.
loadCheckpoint ():Bool Bool Loads the persistent checkpoint and restores all levels and global data.
hasCheckpoint ():Bool Bool Checks if a valid save checkpoint exists.
clearCheckpoint ():Void Void Erases the persistent checkpoint.
captureLevel (state:State<Dynamic>):Void Void Captures all ISaveable entities of the given state in the session cache.
restoreLevel (state:State<Dynamic>):Void Void Applies saved state to all ISaveable entities in the state.
markEntityDestroyed (iid:String, ?levelName:String):Void Void Marks an entity IID as destroyed/collected so it will not spawn again.
setGlobal (key:String, value:Dynamic):Void Void Stores a global game variable.
getGlobal <T>(key:String, ?defaultValue:T):T T Reads a typed global variable with an optional default value.
